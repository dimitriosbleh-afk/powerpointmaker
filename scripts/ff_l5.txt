===== SLIDE 3 =====
  Use of this resource
  Please download the accompanying Teacher Handbook that matches this unit.
  Read the text and familiarise yourself with e.g. key themes, big ideas, characters, themes and literary features.
  This resource is designed to be modified and adapted to suit the individual context and needs of each school, teacher and cohort of students.
  It is recommended that teachers read the lesson detail provided in the Teacher Handbook in preparation for delivering this lesson. This may include:
  identifying which components of the lesson may need adapting, depending on the lesson time available
  pre-reading the specified pages to understand key themes, events and big ideas

As these are repeated across the unit, it is anticipated that the pace of each lesson should increase as students become more confident with newly acquired skills and knowledge.

===== SLIDE 20 =====
  Opening sentence
  Last week, we went to Chinatown with my family to celebrate the Chinese New Year.
  The opening sentence tells us when, where and what the main event is. It also tells us who was there.
  I
  --- EXISTING NOTES ---
  Highlight the opening sentence of the mentor text. Explain that the opening sentence in a recount tells us what the event is, where it was and when it happened. It can also tell us who was there.

===== SLIDE 21 =====
  Detail sentences
  Once we have an opening sentence, we need to create detail sentences.
  These help us explain exactly what happened at the celebration by describing the events in order.
  To create these detail sentences, we can use time connectives.
  I

===== SLIDE 22 =====
  Time connectives
  Time connectives are special words which describe the order in which events happen. We can use these to start our detail sentences and make sure we order the events correctly.
  For example:
  I
  First
  Then
  After that
  --- EXISTING NOTES ---
  Students can count on fingers with each time connective eg. First = 1, Second = 2, After that = 3

  Model how to add detail sentences using time connectives such as ‘first’, ‘then’ and ‘after that’. Explain that these detail sentences show the events in order and describe what happened at the celebration.
  
  Identify the next event (e.g. watching the dragon and lion dance), then model using a time connective (‘then’) to create a detail sentence which describes the event. Make sure to highlight that the detail sentence needs to describe the event clearly, and including a ‘who’ and ‘what doing’. Can call on students to identify the who / what doing.
